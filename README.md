# Replication Package: Stewardship Gaps and Debt Visibility

Replication package for Stewardship Gaps and Debt Visibility:

A Multi-Case Study of Latent Technical Debt in Apache Fineract

Ashhar Ahmad Khan, Jamia Hamdard, 2026

All pull requests and JIRA issues referenced here are publicly

archived under Apache Software Foundation governance and can be

independently verified.

Apache Fineract repository: https://github.com/apache/fineract

## How to use this package

Each file corresponds to a section of the paper's methodology.

Start with pr-jira-mapping.md to locate the primary artefacts,

then use the remaining files to verify each case independently.

## Contents

- pr-jira-mapping.md: maps every PR and JIRA issue to its case and analysis step

- runtime-verification.md: exact commands used to verify Case B at runtime

- dependency-surface-checklist.md: search queries confirming zero consumers for Case B

- thematic-coding-schema.md: category definitions used during mailing list and JIRA analysis

- case-c-instance-index.md: file paths, methods, and DB call counts for all four Case C instances
